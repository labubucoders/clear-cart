ClearCart Chrome Extension (Manifest V3)
========================================

How to install in Google Chrome:
1. Unzip this folder somewhere permanent on your computer.
2. Open Google Chrome and navigate to: chrome://extensions
3. Turn ON "Developer mode" in the top-right corner.
4. Click "Load unpacked" in the top-left corner and select this unzipped folder.
5. Pin ClearCart from the Chrome Extensions puzzle menu and test it on any store or click Settings -> "Test demo site -> Open" to launch ShadyMart.
